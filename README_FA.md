# ربات نوبیتکس EMA256 V2

این نسخه از صفر ساخته شده و پیش‌فرض آن DRY_RUN=true است.

## مشکل 166 کندل
ربات 1500 کندل 1 دقیقه‌ای را در 3 صفحه 500تایی می‌گیرد، duplicateها را حذف می‌کند، سپس آنها را به کندل‌های کامل 3 دقیقه‌ای تبدیل می‌کند. بنابراین دیگر به 166 کندل محدود نمی‌شود.

حداقل 350 کندل 3 دقیقه‌ای برای شروع استراتژی لازم است؛ EMA256 نیز روی همین تاریخچه محاسبه می‌شود.

## نصب Termux
pkg update -y
pkg install python -y
pip install -r requirements.txt
cp .env.example .env
export $(grep -v '^#' .env | xargs)
python bot.py

تا وقتی DRY_RUN=true است هیچ سفارش واقعی ارسال نمی‌شود.

API Key را داخل چت نفرستید.
